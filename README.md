# Calculator

A simple and fully functional browser-based calculator built using **HTML5, CSS3, and Vanilla JavaScript**.

## Features

* Basic arithmetic operations:

  * Addition `+`
  * Subtraction `−`
  * Multiplication `×`
  * Division `÷`
* Numeric buttons `0–9`
* Decimal point support
* Equals button for calculating results
* Clear (`C`) button
* Delete (`DEL`) button
* Division-by-zero error handling
* Sequential operator operations
* Responsive button layout using **CSS Grid**
* Event listeners implemented using JavaScript
* No inline `onclick` attributes
* No use of `eval()`

## 🛠️ Technologies Used

* **HTML5** – Structure of the calculator
* **CSS3** – Styling and CSS Grid layout
* **JavaScript (Vanilla)** – Calculator functionality and logic

## How to Run

1. Clone this repository:

```bash
git clone https://github.com/your-username/calculator.git
```

2. Open the project folder.
3. Open `index.html` in your browser.

No additional installation or dependencies are required.
